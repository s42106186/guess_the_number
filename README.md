# Угадай число

Консольная игра на Python. Проект выполнен в рамках **курсовой работы** по дисциплине «Программирование»

## Возможности

- **Угадать** — компьютер загадывает число, вы угадываете. Есть подсказки «Горячо!», «Тепло.», «Холодно!».
- **Загадать** — вы загадываете число, компьютер угадывает его методом половинного деления по вашим подсказкам `>`, `<`, `+`.
- **Статистика** — итоги сессии: игры, победы, очки, среднее число попыток.
- **Тесты** — встроенное самотестирование (19 проверок).

## Уровни сложности

| Уровень | Диапазон | Попыток |
| --- | --- | --- |
| 1 | 1–10 | 4 |
| 2 | 1–100 | 7 |
| 3 | 1–1000 | 10 |

Очки за победу: `(попыток всего − потрачено + 1) × 10 × уровень`. За поражение очков нет.

## Запуск

Нужен Python 3. Сторонние библиотеки не требуются.

```
python guess_the_number.py
```
